# 双盲信度检验（v2.4.0 分类法）

## 方法

- **抽样**：分层 576 条（133 个叶子每叶 ≥3 条，其余按叶子规模比例分配），覆盖全部叶子与段。
- **盲法**：两份独立标注（标注员 a / b），输入只含 `seq / l1 / component / label / definition`，**不含**原判定；
  两人互不可见，且禁止打开 `examples/` 与彼此的目录。
- **指标**：Krippendorff's α（nominal，两标注员），辅以观测一致率。

## 结果

| 指标 | 值 | 判读 |
|---|---|---|
| **Krippendorff α** | **0.918** | ≥0.75 合格，分类法可靠 |
| 观测一致率 | 91.8% | — |
| 类别数 | 131 | 133 叶中有 2 叶未被抽中 |

按段：

| 段 | n | α | 一致率 |
|---|---|---|---|
| S1 取数规划 | 80 | 0.851 | 86% |
| S2 检索规划 | 70 | 0.939 | 94% |
| S3 结构化取数 | 128 | 0.911 | 91% |
| S4 本地计算 | 80 | 0.974 | 97% |
| S5 网页检索 | 35 | 0.900 | 91% |
| S6 客服知识库 | 44 | 0.821 | 84% |
| S7 记忆 | 11 | 1.000 | 100% |
| S8 能力装载 | 13 | 1.000 | 100% |
| S9 终稿生成 | 115 | 0.918 | 92% |

S6 最弱（0.82），分歧集中在「正文损坏 / 客服答非所问 / 套话」三叶的边界；
S7/S8 是 100% 但样本只有 11/13 条，不能据此认为它们更稳。

## 关键发现：新读者与原判只有 82.5% 一致

| 对比 | 一致率 |
|---|---|
| 标注员 a vs b | 91.8% |
| **a vs 原始归类** | **82.5%** |
| **b vs 原始归类** | **82.3%** |

两个独立标注员之间高度一致，但**都与现有树里的叶子归属差约 17%**。原因不是分类法，而是历史：

现有 13,002 条叶子归属是在 **v1（91 叶）** 口径下产生的，之后经历了两次机械迁移
（5 段→7 段→9 段）、33 组叶子按段二分、5 个联合叶用子代理重标、22 个叶子改名。
迁移保证了**计数不丢**，但不保证**每条的叶子归属在 v2.4 口径下仍然最优**。

## 结论

1. **分类法本身是可靠的**（α=0.918），可以对外说"这套口径两个人独立读能得同一结论"。
2. **树里的叶子计数存在约 17% 的口径漂移**，段级与机制级计数不受影响（那是机械映射），
   叶子级排名需谨慎，尤其 S1 / S9（与原判一致率 74% / 73%）。
3. 要消除漂移：用当前 v2.4 分类法对 13,002 条做一次全量重标（67 分片、8 并发，约 40 分钟），
   重标后段级/机制级结论不会变，叶子级排名会变。

## 体积策略

`item_index.jsonl` 单份约 15 MB，两份示例会让仓库膨胀。约定：

- **只保留最近一批的完整产物**（含 `item_index.jsonl`）；
- 历史批次只留 `cluster_tree.json` / `cluster_summary.md` / `MANIFEST.json`，用于对照口径；
- 需要历史批次的索引时，用对应版本的 `taxonomy/` 重跑 `aggregate` 即可再生。

v1.1.0 的索引已按此约定裁掉（`git` 历史里仍有，工作区不再占用）。

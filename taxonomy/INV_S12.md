# 环节 S12：任务编排

决定做几步、按什么顺序、要不要先补前置（技能流程、基期、核对）。不是取数查询设计，也不是检索词构造。

## 0. 判定骨架（按顺序问，命中即停）

1. **这一环该做的动作，一点都没做？** → `S12.M1.1` 空编排 / `S12.M1.2` 编排未下发 / `S12.M1.3` 追问后未重排
2. **动作做了，但对象/指标/时段/范围不是用户要的？** → `S12.M2.1` 任务意图判错 / `S12.M2.2` 漏必要步骤 / `S12.M2.3` 步骤依赖顺序错 / `S12.M2.4` 子问题拆解错 / `S12.M2.5` 编排范围过泛 / `S12.M2.6` 编排重复
3. **调用报错/超时/零行/空返回/被截断？** → `S12.M3.1` 编排输出不可用
6. **结论没证据，或与已有证据相反？** → `S12.M6.1` 未执行即下结论

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S12.M1.1` 空编排

- **定义**：需要多步才能完成的任务，编排环节没有产出任何子任务，本轮零动作下发。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：计划为空数组、只回一句「我来处理」而没有子任务；下游只能用旧上下文作答。
- **排除**：有子任务但没下发 → `S12.M1.2`；子任务漏了关键步骤 → `S12.M2.2`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：任务规划

### `S12.M1.2` 编排未下发

- **定义**：已经排出子任务，但没有一条被执行，计划停在纸面。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：计划里 N 个子任务、实际调用 0 条；或只做了计划外的动作。
- **排除**：子任务执行报错 → 落到对应执行段的叶子；计划本身为空 → `S12.M1.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：失败 ｜ **组件**：任务规划

### `S12.M1.3` 追问后未重排

- **定义**：用户补充或纠正后，编排没有基于新信息重排，仍沿用上一轮的计划。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：多轮会话里用户补齐条件后，本轮子任务与上一轮逐字相同。
- **排除**：重排了但漏步骤 → `S12.M2.2`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：任务规划

### `S12.M2.1` 任务意图判错

- **定义**：把任务类型判错：该走操作指引的当成数据分析、该多步的当成一次性问答、该追问的当成可执行任务。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：问「怎么设置」却被拆成取数任务；问预测却排了取数与计算。
- **排除**：意图对但步骤漏 → `S12.M2.2`；完全没排动作 → `S12.M1.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：任务规划

### `S12.M2.2` 漏必要步骤

- **定义**：编排缺少完成任务必需的步骤：漏取基期、漏核对口径、漏装载技能、漏补一问的后续动作。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：算同比没排上年同期；要求按技能流程核对却没排装载技能；多步任务只排第一步。
- **排除**：步骤排了但执行失败 → 对应执行段；完全没排 → `S12.M1.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：任务规划

### `S12.M2.3` 步骤依赖顺序错

- **定义**：子任务之间的先后与依赖排错：先算后取、在数据就绪前渲染、并行做了本该串行的事。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：没有基期数据就排同比计算并直接出图；依赖前一步结果却同时发起。
- **排除**：步骤齐全但执行失败 → 落到对应执行段的叶子。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：任务规划

### `S12.M2.4` 子问题拆解错

- **定义**：把一个问题拆错：拆成互不相干的两块、该合的不合、多标的只拆一个、复合条件只取其一。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：「A 和 B 的对比」只排了 A；「营收与净利」合并成一个任务丢维度。
- **排除**：拆对了但漏某一步 → `S12.M2.2`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：任务规划

### `S12.M2.5` 编排范围过泛

- **定义**：子任务没有任何范围约束，等于把全市场全时段都拉一遍。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：「高股息龙头」只排「取全部 A 股股息率」，无行业/市值/时间限制。
- **排除**：范围写了但过窄导致零行 → `S10.M2.5`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：任务规划

### `S12.M2.6` 编排重复

- **定义**：同一子任务被重复编排，或把已完成的步骤再排一遍。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：一轮里对同一字段连排三次相同查询；原句与结构化字段各排一条。
- **排除**：编排里就重复下发同样的请求 → `S10.M2.9`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：任务规划

### `S12.M3.1` 编排输出不可用

- **定义**：编排输出被截断、结构损坏或解析失败，无法据此执行。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：计划 JSON 不闭合、最后一条子任务写到一半、解析报错只剩一句自然语言。
- **排除**：计划为空但结构完整 → `S12.M1.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：失败 ｜ **组件**：任务规划

### `S12.M6.1` 未执行即下结论

- **定义**：编排层面就放弃执行，直接凭上下文或常识给出结论性判断。（本叶仅收S12段产生的缺陷）
- **可观测信号**：–
- **纳入**：计划里写「数据不可得，直接回答」并给出具体数值或结论。
- **排除**：执行了但没查到后编造 → `S9` 的编造类叶子。
- **最相近的类别**：`–` — 区分点：–
- **标签**：编造 ｜ **组件**：任务规划

# 环节 S4：本地计算

在本地做取数编排、计算与图表。含 shell 代码解释器、持仓查询。失效多为脚本报错、数据占位、产物空白。

## 0. 判定骨架（按顺序问，命中即停）

1. **这一环该做的动作，一点都没做？** → `S4.M1.2` 参数为空被拦截，没执行
2. **动作做了，但对象/指标/时段/范围不是用户要的？** → `S4.M2.1` 持仓标的映射错 / `S4.M2.7` 脚本过滤失效
3. **调用报错/超时/零行/空返回/被截断？** → `S4.M3.1` 调用参数解析报错 / `S4.M3.10` 执行环境不可用 / `S4.M3.2` 脚本调用报错 / `S4.M3.3` 脚本筛选条件写死 / `S4.M3.4` 脚本零行仍报成功 / `S4.M3.5` 脚本报错退出 / `S4.M3.6` 接口参数不被支持 / `S4.M3.7` 脚本错误体当成功 / `S4.M3.8` 脚本输出被截断 / `S4.M3.9` 鉴权失败返回空持仓
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S4.M4.1` 脚本字段被静默丢弃 / `S4.M4.2` 脚本只回标识列 / `S4.M4.4` 脚本行数失控 / `S4.M4.5` 脚本结果缺时点 / `S4.M4.6` 脚本缺值用占位顶替 / `S4.M4.7` 持仓返回过期快照 / `S4.M4.8` 没行情也返回成功图表
5. **数据对，但换算/聚合/口径/比较错，或自相矛盾？** → `S4.M5.1` 脚本期间口径错 / `S4.M5.3` 脚本聚合窗口算错 / `S4.M5.4` 脚本标签数值错位
6. **结论没证据，或与已有证据相反？** → `S4.M6.1` 脚本固定结论
7. **形式与完整性不达标（缺项/格式/语言/答非所问）？** → `S4.M7.1` 图表产物不可用

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S4.M1.2` 参数为空被拦截，没执行  ·  6 条 / 4 会话

- **定义**：调用参数为空 {}、重复守卫命中或只执行首个对象，实际动作未落地却返回成功。
- **可观测信号**：参数 {} / 重复守卫命中 / 多对象只执行首个
- **纳入**：含多对象拼接只跑第一个、重复调用被守卫吞掉。
- **排除**：参数非空但被后端拒绝 → S4.M3.6。
- **最相近的类别**：`S4.M3.6` — 区分点：动作没落地 → 本叶；落地后被拒 → M3.6
- **标签**：失败 ｜ **组件**：shell
- **正例**：seq=5940「shell 空参数调用静默成功返回」；seq=12894「shell 空参数执行返回成功空输出」
- **反例（属 `S4.M3.6`，不属本叶）**：seq=5964「shell 执行的 finquery 筛选请求 schema」

### `S4.M2.1` 持仓标的映射错  ·  2 条 / 2 会话

- **定义**：把请求中的标的（公司/代码/指数/ETF/币种/商品）链接成另一只证券或另一市场品种，并以该标的的数据正常返回。（本叶仅收 shell 代码解释器 产生的缺陷）
- **可观测信号**：返回标的≠请求标的，但查询语义本身正确
- **纳入**：返回数据的标的与用户所指不一致，但查询语义本身没问题。
- **排除**：后端把正确代码替换成别家（代码无误）→ S4.M4.6。
- **最相近的类别**：`S4.M4.6` — 区分点：请求侧映射错 → 本叶；后端把正确代码换掉 → M4.6
- **标签**：实体 ｜ **组件**：shell
- **正例**：seq=2953「shell 解析产物未校验标的身份，ASTS 命名文件的」；seq=5958「finquery 产物读取层级错误导致数据与查询币种不符」
- **反例（属 `S4.M4.6`，不属本叶）**：seq=2351「shell 全 None 输出仍报成功」

### `S4.M2.7` 脚本过滤失效  ·  1 条 / 1 会话

- **定义**：过滤范围、主题词或板块映射与请求不符，返回全市场或错误板块的数据。（本叶仅收 shell 代码解释器 产生的缺陷）
- **可观测信号**：返回全市场行、无有效 WHERE
- **纳入**：含“半导体”被映射成地区主题、缺标的过滤返回全市场无关行。
- **排除**：返回行数正常但内容不相关 → S4.M4.1。
- **最相近的类别**：`S4.M4.4` — 区分点：该过滤没过滤 → 本叶；行数失控但条件在 → M4.4
- **标签**：实体 ｜ **组件**：shell
- **正例**：seq=6692「finquery 主题检索返回错主题标的池」
- **反例（属 `S4.M4.4`，不属本叶）**：seq=2290「行权价区间过滤截断期权链，OI 墙判断基于不完整切片」

### `S4.M3.1` 调用参数解析报错  ·  6 条 / 6 会话

- **定义**：取数服务在问句解析/规范化环节直接失败，返回负 status_code（-3222/-3223/-3226/-3300/-3001 等）与“问句解析结果异常”，row_count/code_count 为 0。（本叶仅收 shell 代码解释器 产生的缺陷）
- **可观测信号**：status_code -32xx/-3001；未生成有效 SQL；row_count=0
- **纳入**：finquery 侧解析阶段报错，未进入 SQL 执行。
- **排除**：SQL 已生成但执行报错 → S4.M3.2。
- **最相近的类别**：`S4.M3.2` — 区分点：失败在解析段 → 本叶；SQL 已生成、执行报错 → M3.2

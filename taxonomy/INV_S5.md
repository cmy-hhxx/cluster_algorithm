# 环节 S5：网页检索

执行外部网页检索与抓取。含 web_search、web_fetch。失效多为召回不相关、时效过期、正文不可用。

## 0. 判定骨架（按顺序问，命中即停）

3. **调用报错/超时/零行/空返回/被截断？** → `S5.M3.1` 抓取失败返回全空字段
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S5.M4.1` 搜回错误对象 / `S5.M4.2` 搜回过期页面 / `S5.M4.3` 正文抽不出，只剩样板 / `S5.M4.4` 页面相关但没那个字段 / `S5.M4.5` 同一页反复返回 / `S5.M4.6` 同一指标多个价

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S5.M3.1` 抓取失败返回全空字段  ·  20 条 / 17 会话

- **定义**：web_fetch 对目标 URL 执行失败（fetched=false），但返回对象把 title/source/publish_time/content 全填空串，且不携带状态码或失败原因。
- **可观测信号**：fetched=false 且 title/source/publish_time/content 全空
- **纳入**：仅适用 web_fetch，且返回字段全空、无错误说明。
- **排除**：抓到错误页/反爬页正文 → S.M4.3。
- **最相近的类别**：`S5.M4.3` — 区分点：抓取失败无内容 → 本叶；抓到错误页正文 → M4.3
- **标签**：失败 ｜ **组件**：web_fetch、web_search
- **正例**：seq=5962「web_fetch 抓取失败返回全空字段且无错误原因」；seq=12940「网页抓取失败时静默返回空壳结果，未报错」
- **反例（属 `S5.M4.3`，不属本叶）**：seq=4「检索条目正文为Cookie/页脚样板且发布时间为空」

### `S5.M4.1` 搜回错误对象  ·  418 条 / 320 会话

- **定义**：检索成功且返回非空，但条目实体、市场/品种、方向、页面类型或体裁与查询不一致，整批结果无法作为候选材料。
- **可观测信号**：条目实体/市场/页型/体裁与查询不符
- **纳入**：含问 A 返回 B、限定 MCX 返回 CME、要正文返回首页/索引页/科普页、多标的中某个零覆盖。
- **排除**：对象正确但缺数据类型 → S.M4.4。
- **最相近的类别**：`S5.M4.4` — 区分点：对象就不对 → 本叶；对象对但缺字段 → M4.4
- **标签**：实体 ｜ **组件**：web_search
- **正例**：seq=4617「检索结果实体与查询主体不一致，页面未清洗」；seq=2676「检索结果与查询的市场/标的限定不符（返回域外美股内容）」
- **反例（属 `S5.M4.4`，不属本叶）**：seq=8182「检索结果关键数值字段为空占位且主题年份错位」

### `S5.M4.2` 搜回过期页面  ·  543 条 / 420 会话

- **定义**：查询已给日期/时窗/"最新"限定，返回条目仍以远早于目标期的页面为主，或 publish_time 为空、与正文日期互斥，工具不做时效过滤或标注。
- **可观测信号**：publish_time 为空，或页面日期远早于目标期
- **纳入**：含旧季报、旧 13F、旧盘前快照、元数据日期倒置。
- **排除**：同批多值冲突不在日期 → S.M4.6。
- **最相近的类别**：`S5.M4.6` — 区分点：日期层面失效 → 本叶；同批多值冲突 → M4.6
- **标签**：时效 ｜ **组件**：web_fetch、web_search
- **正例**：seq=9134「检索结果时效元数据缺失或过期」；seq=11357「检索结果时效缺失/陈旧」
- **反例（属 `S5.M4.6`，不属本叶）**：seq=1993「RSI 检索结果内部数值冲突且时点滞后」

### `S5.M4.3` 正文抽不出，只剩样板  ·  664 条 / 523 会话

- **定义**：条目存在但正文为空串、是 Cookie 同意声明、反爬/错误页、页脚版权样板，或摘要被硬截断，关键字段缺失。
- **可观测信号**：content 为空串/Cookie 声明/反爬页/页脚导航/硬截断
- **纳入**：含整页正文重复塞入同一文档。
- **排除**：正文可读但对象错 → S.M4.1。
- **最相近的类别**：`S5.M4.4` — 区分点：正文没抽出来 → 本叶；正文在但缺字段 → M4.4
- **标签**：呈现 ｜ **组件**：web_fetch、web_search
- **正例**：seq=4「检索条目正文为Cookie/页脚样板且发布时间为空」；seq=2346「web_search 结果混入页面装饰并返回过期条目」
- **反例（属 `S5.M4.4`，不属本叶）**：seq=8182「检索结果关键数值字段为空占位且主题年份错位」

### `S5.M4.4` 页面相关但没那个字段  ·  105 条 / 95 会话

- **定义**：条目与主题相关，但不含所请求的数据类型（目标价、期权合约、成分股名单、EMA/RSI 数值），或只返回空表/占位结构。
- **可观测信号**：页面主题相关、正文可读，但不含目标价/名单/指标
- **纳入**：对象正确、体裁正确，只是缺具体字段。
- **排除**：完全无关的页面 → S.M4.1。
- **最相近的类别**：`S5.M4.3` — 区分点：缺具体字段 → 本叶；正文不可用 → M4.3
- **标签**：缺失 ｜ **组件**：web_search
- **正例**：seq=8182「检索结果关键数值字段为空占位且主题年份错位」；seq=2838「网页检索结果与查询目标不匹配（未返回所需成分股名单/同业」
- **反例（属 `S5.M4.3`，不属本叶）**：seq=4「检索条目正文为Cookie/页脚样板且发布时间为空」

### `S5.M4.5` 同一页反复返回  ·  250 条 / 220 会话

- **定义**：不同查询返回同一批页面未去重，或单次返回整页正文导致体量异常膨胀，挤占上下文。
- **可观测信号**：同一文档跨 query 重复出现；单条返回数万字符
- **纳入**：含同一文档在多个 query 结果中重复出现、单条返回数万字符。
- **排除**：内容本身错误 → S.M4.3。
- **最相近的类别**：`S5.M4.3` — 区分点：重复/体量 → 本叶；内容为空 → M4.3
- **标签**：呈现 ｜ **组件**：web_fetch、web_search
- **正例**：seq=11192「网页检索返回整页正文且跨查询重复同一文档，单次返回体积异」；seq=9476「跨查询重复返回整页长文，关键事实被淹没未进入下一轮」
- **反例（属 `S5.M4.3`，不属本叶）**：seq=4「检索条目正文为Cookie/页脚样板且发布时间为空」

### `S5.M4.6` 同一指标多个价  ·  105 条 / 98 会话

- **定义**：同一指标在同批结果中给出多个互相矛盾的数值（价格、市值、目标价、RSI），冲突点不在日期而在取值来源。
- **可观测信号**：同一指标多值并列且互斥，未标优先级或时点
- **纳入**：多源并列且未标注优先级或时点。
- **排除**：冲突可由发布日不同解释 → S.M4.2。
- **最相近的类别**：`S5.M4.2` — 区分点：数值冲突 → 本叶；日期过期 → M4.2
- **标签**：口径 ｜ **组件**：web_search
- **正例**：seq=1993「RSI 检索结果内部数值冲突且时点滞后」；seq=3088「检索摘要季度口径过期且互相冲突」
- **反例（属 `S5.M4.2`，不属本叶）**：seq=9134「检索结果时效元数据缺失或过期」

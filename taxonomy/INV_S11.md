# 环节 S11：图表与可视化

把数据落成图：选图型、写渲染 spec、执行渲染、挂进正文。失效多为 spec 不合契约、序列缺项、数值/换算错、图没渲染或引用挂不上。

## 0. 判定骨架（按顺序问，命中即停）

1. **这一环该做的动作，一点都没做？** → `S11.M1.1` 未产出图表
2. **动作做了，但对象/指标/时段/范围不是用户要的？** → `S11.M2.1` 图表类型选错 / `S11.M2.2` 图表字段选错
3. **调用报错/超时/零行/空返回/被截断？** → `S11.M3.1` 渲染 spec 不合契约 / `S11.M3.2` 渲染执行报错
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S11.M4.1` 图表数据序列缺项
5. **数据对，但换算/聚合/口径/比较错，或自相矛盾？** → `S11.M5.1` 图表换算系数错 / `S11.M5.2` 图表正文数值不一致
6. **结论没证据，或与已有证据相反？** → `S11.M6.1` 图表写死无来源数值
7. **形式与完整性不达标（缺项/格式/语言/答非所问）？** → `S11.M7.1` 图表引用解析失败 / `S11.M7.2` 图未渲染只留占位

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S11.M1.1` 未产出图表

- **定义**：要求出图却没有任何 spec 或渲染调用，本轮零图表产物。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：tasks/answer 里只有表格文字，没有任何 display 或 workflow 请求；用户要的图不存在。
- **排除**：生成了 spec 但被校验拦下 → `S11.M3.1`；spec 生成了但没渲染 → `S11.M7.2`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：display

### `S11.M2.1` 图表类型选错

- **定义**：选了表达不了该数据的图型：该用 K 线画成柱状、该用走势画成表格、多标的硬塞进单序列。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：时间序列画成饼图、需要展示区间却只给一个点、多标的比较只画一条线。
- **排除**：图型对但字段/单位错 → `S11.M2.2`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：呈现 ｜ **组件**：display

### `S11.M2.2` 图表字段选错

- **定义**：图型对，但画错了指标或时间区间：坐标轴标的不是请求的字段、起止日期与请求不一致。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：把「成交量」画成「成交额」、把请求的区间画成另一段、多标的只画了其中一个。
- **排除**：图型选错 → `S11.M2.1`；单位没换算 → `S11.M5.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：口径 ｜ **组件**：display

### `S11.M3.1` 渲染 spec 不合契约

- **定义**：渲染 spec 违反组件契约：出现契约外的顶层字段、通道缺必需属性、参数类型错（如 maLine 传标量）。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：spec 校验报「未知字段」、y 通道没有 axis、均线参数不是正整数数组。
- **排除**：spec 合契约但渲染报错 → `S11.M3.2`；被拒后完全没有产物 → `S11.M1.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：失败 ｜ **组件**：display

### `S11.M3.2` 渲染执行报错

- **定义**：spec 通过校验，但渲染阶段组件报错或超时，没有产出可用图表。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：workflow 抛异常、组件 500、渲染超时且无降级。
- **排除**：spec 本身不合契约 → `S11.M3.1`；渲染成功但产物空白 → `S11.M7.2`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：失败 ｜ **组件**：display

### `S11.M4.1` 图表数据序列缺项

- **定义**：图出来了，但缺必需元素：少一条 series、没有坐标轴标签、图例与数据对不上、区间只剩半段。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：双指标图只画了一条线、y 轴没有任何刻度、图例写着三个标的但只有两条线。
- **排除**：整图不存在 → `S11.M1.1`；数值错 → `S11.M5.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：缺失 ｜ **组件**：display

### `S11.M5.1` 图表换算系数错

- **定义**：图上的数值换算错一个量级或一个口径：万手→手系数取错、亿元没换算到元、复权和未复权混用。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：万手→手用 ×1000、标签写「亿元」刻度却是万元、同一张图两条序列用了不同复权口径。
- **排除**：字段选错 → `S11.M2.2`；与正文数值不一致 → `S11.M5.2`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：单位 ｜ **组件**：display

### `S11.M5.2` 图表正文数值不一致

- **定义**：同一答复里图表与正文/表格给出不同数值或不同区间，且没有说明以哪个为准。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：正文写涨 3.2%，图上标注 2.8%；表格 10 只、图里 12 根柱。
- **排除**：单个图表内部算错 → `S11.M5.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：口径 ｜ **组件**：display

### `S11.M6.1` 图表写死无来源数值

- **定义**：把估算、占位或编造的数值写进图表数据，且没有来源或说明，视觉上却像真实数据。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：数据序列里出现无出处的估算值、注释写「约」但图上当精确值呈现。
- **排除**：有来源但算错 → `S11.M5.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：编造 ｜ **组件**：display

### `S11.M7.1` 图表引用解析失败

- **定义**：图已渲染成产物，但正文引用（vis-html / 图号）解析不出来，读者看不到图或挂错位置。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：引用标签指向不存在的产物、图挂在无关段落、正文说「见下图」而引用失效。
- **排除**：图根本没渲染 → `S11.M7.2`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：呈现 ｜ **组件**：display

### `S11.M7.2` 图未渲染只留占位

- **定义**：渲染失败或 html_len=0，却仍以「已生成/见下图」交付，正文没有任何实际产物。（本叶仅收S11段产生的缺陷）
- **可观测信号**：–
- **纳入**：答复里只有占位符或空 div、说明写了图但产物为空。
- **排除**：引用解析失败但产物存在 → `S11.M7.1`。
- **最相近的类别**：`–` — 区分点：–
- **标签**：呈现 ｜ **组件**：display

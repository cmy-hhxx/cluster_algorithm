# 环节 S9：答案合成

把已有材料组织成最终答复与中间产物（答案合成）。含答案合成、中间推理处理。失效多为编造、口径错、引用错挂、答非所问。

## 0. 判定骨架（按顺序问，命中即停）

1. **这一环该做的动作，一点都没做？** → `S9.M1.1` 整段无实质内容 / `S9.M1.2` 取回的数据没写进答案
2. **动作做了，但对象/指标/时段/范围不是用户要的？** → `S9.M2.1` 答错对象：把 A 当成 B / `S9.M2.2` 口径答偏：问这答那
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S9.M4.1` 残缺材料当完整证据
5. **数据对，但换算/聚合/口径/比较错，或自相矛盾？** → `S9.M5.1` 旧数据当当前值 / `S9.M5.2` 同一答复内数值矛盾 / `S9.M5.3` 数值推算算错 / `S9.M5.4` 指标含义认错 / `S9.M5.5` 换算算错 / `S9.M5.6` 多标的汇总重复计数
6. **结论没证据，或与已有证据相反？** → `S9.M6.1` 编造不存在的对象 / `S9.M6.2` 违背已有证据 / `S9.M6.3` 证据不足仍下绝对结论 / `S9.M6.4` 凭空补出数值 / `S9.M6.5` 引用来源错挂 / `S9.M6.6` 取数失败被说成业务结论 / `S9.M6.7` 多源冲突未核验
7. **形式与完整性不达标（缺项/格式/语言/答非所问）？** → `S9.M7.1` 正文泄漏内部标记 / `S9.M7.2` 图没渲染只留占位 / `S9.M7.3` 答复不可读 / `S9.M7.4` 漏交付要求内容

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S9.M1.1` 整段无实质内容

- **定义**：对可回答的请求直接拒答、只给泛化免责声明，或整段未回应，用户拿不到任何实质内容。
- **可观测信号**：回答仅免责声明/复述问题，无任何结论
- **纳入**：含“无法提供/不构成投资建议”式空转、只复述问题。
- **排除**：已取回材料但没写进答案 → S9.M1.2。
- **最相近的类别**：`S9.M1.2` — 区分点：没内容 → 本叶；有材料没用 → M1.2
- **标签**：缺失 ｜ **组件**：中间推理处理、答案合成

### `S9.M1.2` 取回的数据没写进答案

- **定义**：链路已取回可用数据，终稿却沉默跳过、换源或把问题抛回用户，材料未参与结论。
- **可观测信号**：上下文有工具结果，答案未引用、换源或抛回用户
- **纳入**：含弃用已取回的筛选结果、明明有数据仍说“未获取”。
- **排除**：否认或反转在手数据 → S9.M6.2。
- **最相近的类别**：`S9.M6.2` — 区分点：沉默跳过 → 本叶；否认/反转 → M6.2
- **标签**：缺失 ｜ **组件**：中间推理处理、答案合成

### `S9.M2.1` 答错对象：把 A 当成 B

- **定义**：终稿讨论的标的、公司身份或代码与用户所指不一致（同名混淆、把 A 写成 B、把指数写成个股）。
- **可观测信号**：答案讨论的标的/公司/代码≠用户所指
- **纳入**：含回答对象集合偏离用户指代的公司组。
- **排除**：口径/维度偏离 → S9.M2.2。
- **最相近的类别**：`S9.M2.2` — 区分点：对象错 → 本叶；对象对口径错 → M2.2
- **标签**：实体 ｜ **组件**：中间推理处理、答案合成

### `S9.M2.2` 口径答偏：问这答那

- **定义**：标的正确但回答的指标、时段、场景或人群口径不是用户问的那个（问日间答晚间、问季度答年度、问 A 股答美股）。
- **可观测信号**：指标/时段/场景与提问不符（问日间答晚间）
- **纳入**：含把用户限定条件改写后作答。
- **排除**：实体层面就错 → S9.M2.1。
- **最相近的类别**：`S9.M2.1` — 区分点：口径错 → 本叶；对象错 → M2.1
- **标签**：口径 ｜ **组件**：中间推理处理、答案合成

### `S9.M4.1` 残缺材料当完整证据

- **定义**：拿到的材料本身残缺（空页、截断、缺字段），终稿仍当作完整证据使用并据此下结论。
- **可观测信号**：材料截断/空页/缺字段，仍据此下结论
- **纳入**：含以 Cookie 页/空表为依据作答。
- **排除**：材料完整但被误读 → A.M5.x。
- **最相近的类别**：`S9.M1.2` — 区分点：用了残缺材料 → 本叶；没用材料 → M1.2
- **标签**：缺失 ｜ **组件**：中间推理处理、答案合成

### `S9.M5.1` 旧数据当当前值

- **定义**：把历史值、旧快照或不同时点的数据混用：旧价当现价、跨时点拼接、时点未对齐却直接比较。
- **可观测信号**：数值对应旧时点；未标 as-of；跨时点直接比较
- **纳入**：含用上季度数据回答“最新”、把两次检索结果当同一时点。
- **排除**：时点正确但单位错 → S9.M5.5。
- **最相近的类别**：`S9.M6.4` — 区分点：有来源但时点错 → 本叶；无来源 → M6.4
- **标签**：时效 ｜ **组件**：中间推理处理、答案合成

### `S9.M5.2` 同一答复内数值矛盾

- **定义**：同一答复内前后数字或结论互相冲突（正文说涨、表格为跌；两处给出不同数值）。
- **可观测信号**：两处数字或结论互相冲突
- **纳入**：含与本轮输入材料中的数值冲突。
- **排除**：单处算错 → S9.M5.3。
- **最相近的类别**：`S9.M5.3` — 区分点：前后不一致 → 本叶；单处算错 → M5.3
- **标签**：口径 ｜ **组件**：答案合成

### `S9.M5.3` 数值推算算错

- **定义**：加减乘除、百分比、估值倍数、财务推算算错，算式可复现地出错。
- **可观测信号**：百分比/倍数/CAGR/同比 可复现地算错
- **纳入**：含 CAGR/同比/占比计算错误、取整导致量级偏差。
- **排除**：口径理解错 → S9.M5.4。
- **最相近的类别**：`S9.M5.4` — 区分点：算式错 → 本叶；口径理解错 → M5.4
- **标签**：口径 ｜ **组件**：中间推理处理、答案合成

### `S9.M5.4` 指标含义认错

- **定义**：指标语义被张冠李戴（把 TTM 当季度、把营收当利润、把涨幅当收益率），或统计口径（复权、样本、分位）理解错。
- **可观测信号**：字段对但定义用错（TTM 当季度、营收当利润）
- **纳入**：含概念定义错误但数值本身来自正确字段。
- **排除**：字段被顶替取错 → S3.M2.4。
- **最相近的类别**：`S9.M5.3` — 区分点：定义错 → 本叶；算错 → M5.3
- **标签**：口径 ｜ **组件**：答案合成

### `S9.M5.5` 换算算错

- **定义**：币种（美元/港元/卢比）、单位（万/亿/百万）、量纲（股/手）换算错误导致数值失真。
- **可观测信号**：USD/HKD/INR 混用；万/亿、股/手 差量级
- **纳入**：含市值与成交量量纲混用。
- **排除**：算式本身错 → S9.M5.3。
- **最相近的类别**：`S9.M5.3` — 区分点：换算错 → 本叶；算式错 → M5.3
- **标签**：单位 ｜ **组件**：答案合成

### `S9.M5.6` 多标的汇总重复计数

- **定义**：对多标的/多期做聚合、计数、去重时算错：重复计数、漏算成员、均值口径不一致。
- **可观测信号**：名单数量与列举不一致；同一标的重复计
- **纳入**：含名单类回答的数量与列举不一致。
- **排除**：单条数值算错 → S9.M5.3。
- **最相近的类别**：`S9.M5.3` — 区分点：聚合计数错 → 本叶；单值算错 → M5.3
- **标签**：多标的 ｜ **组件**：中间推理处理、答案合成

### `S9.M6.1` 编造不存在的对象

- **定义**：输出不存在的事实：编造公司/产品/人名、编造财报披露、编造 App 页面与按钮路径、编造事件。
- **可观测信号**：出现材料中不存在的公司/公告/菜单/按钮路径
- **纳入**：含以残缺工具返回为依据补全具体产品名与界面路径。
- **排除**：数值无来源但非实体编造 → S9.M6.4。
- **最相近的类别**：`S9.M6.4` — 区分点：编实体 → 本叶；编数值 → M6.4
- **标签**：编造 ｜ **组件**：答案合成

### `S9.M6.2` 违背已有证据

- **定义**：手里已有证据，终稿却明确否认该证据、给出相反结论，或把“检索为空”说成别的原因。
- **可观测信号**：称"未获取"但上下文有数据；结论与证据反向
- **纳入**：含把零结果改写成“索引延迟”“数据未更新”。
- **排除**：沉默跳过材料 → S9.M1.2。
- **最相近的类别**：`S9.M1.2` — 区分点：明确否认 → 本叶；沉默跳过 → M1.2
- **标签**：编造 ｜ **组件**：答案合成

### `S9.M6.3` 证据不足仍下绝对结论

- **定义**：材料只支持部分或不确定判断，终稿仍给出“必然/一定/全部”式结论，或把个案外推为普遍规律。
- **可观测信号**："必然/全部/一定"式断言，材料只部分支持
- **纳入**：含无标准答案场景下的绝对化预测。
- **排除**：完全无材料 → S9.M6.1。
- **最相近的类别**：`S9.M6.4` — 区分点：强度越界 → 本叶；数值凭空 → M6.4
- **标签**：编造 ｜ **组件**：答案合成

### `S9.M6.4` 凭空补出数值

- **定义**：正文出现材料中没有的具体数值、价位、目标价、涨跌幅，且未标注来源或估算。
- **可观测信号**：具体数值/价位/涨跌幅 无来源、无算式
- **纳入**：含把占位值/示例值当作真实数据写入。
- **排除**：来源存在但挂错 → S9.M6.5。
- **最相近的类别**：`S9.M6.1` — 区分点：编数值 → 本叶；编实体 → M6.1
- **标签**：编造 ｜ **组件**：答案合成

### `S9.M6.5` 引用来源错挂

- **定义**：引用标注的来源与实际数据对不上：引用编号错位、来源页与数值不对应、把 A 页的结论挂到 B 数据上。
- **可观测信号**：引用编号/来源与数据不匹配；多源冲突未核验
- **纳入**：含引用编号错位、把网页日期当数据日期。
- **排除**：数值凭空出现 → S9.M6.4。
- **最相近的类别**：`S9.M6.7` — 区分点：引用来源错挂 → 本叶；多源冲突未核验 → S9.M6.7
- **标签**：编造 ｜ **组件**：中间推理处理、答案合成

### `S9.M6.6` 取数失败被说成业务结论

- **定义**：取数/检索失败或零行返回，终稿不披露失败，直接把“无数据”解释成业务结论（如“无持仓”“该股无风险”）。
- **可观测信号**：零行/失败被解释成"没有/不存在/已清仓"
- **纳入**：含零行被解读为“不存在”“已清仓”。
- **排除**：明确说明未取到数据并降低结论强度 → 不算缺陷。
- **最相近的类别**：`S9.M6.3` — 区分点：把失败当结论 → 本叶；证据不足下绝对结论 → M6.3
- **标签**：编造,缺失 ｜ **组件**：中间推理处理、答案合成

### `S9.M6.7` 多源冲突未核验

- **定义**：同一指标出现多个来源且数值冲突时，未核验、未标注优先级就择一采用。
- **可观测信号**：同一指标出现多个来源且数值冲突时，未核验、未标注优先级就择一采用。
- **纳入**：仅收 多源冲突未核验 这一类；具体现象见 definition。
- **排除**：若属于「引用来源错挂」→ S9.M6.5。
- **最相近的类别**：`S9.M6.5` — 区分点：多源冲突未核验 → 本叶；引用来源错挂 → S9.M6.5
- **标签**：编造 ｜ **组件**：答案合成

### `S9.M7.1` 正文泄漏内部标记

- **定义**：正文残留内部标记（[citation:1]、<ref>、占位符、JSON 片段、未翻译中文词片），可读性与专业性受损。
- **可观测信号**：正文残留 [citation:1]/<ref>/JSON 片段
- **纳入**：含错误 JSON 原样泄漏。
- **排除**：内容缺失 → S9.M7.4。
- **最相近的类别**：`S9.M7.3` — 区分点：内部标记泄漏 → 本叶；语言排版问题 → M7.3
- **标签**：呈现 ｜ **组件**：中间推理处理、答案合成

### `S9.M7.2` 图没渲染只留占位

- **定义**：图表未生成或 html_len=0，却以“已生成/见下图”占位交付，正文无实际产物。
- **可观测信号**：html_len=0 或未生成，仍写"见下图"
- **纳入**：含空白图、悬空引用。
- **排除**：产物存在但解析失败 → S11.M7.1。
- **最相近的类别**：`S11.M7.1` — 区分点：没生成 → 本叶；生成了引用坏 → M3.1
- **标签**：呈现 ｜ **组件**：中间推理处理、答案合成

### `S9.M7.3` 答复不可读

- **定义**：答复语言与提问语种不符、混用未翻译片段，或排版结构崩坏（表格错位、层级混乱）导致不可读。
- **可观测信号**：语种不符、混入未翻译片段、表格/层级崩坏
- **纳入**：含中文问句返回英文、正文夹杂原文。
- **排除**：内容本身错误 → A.M5/A.M6。
- **最相近的类别**：`S9.M7.1` — 区分点：可读性问题 → 本叶；内部标记 → M7.1
- **标签**：语言 ｜ **组件**：中间推理处理、答案合成

### `S9.M7.4` 漏交付要求内容

- **定义**：内容切题但漏交付用户明确要求的部分：少答一个标的、少一个子问题、少要求的口径或章节。
- **可观测信号**：多标的只答其一；遗漏用户明确要求的子问题
- **纳入**：含多标的只答其一、要求对比只给单边。
- **排除**：整体未回应 → S9.M1.1。
- **最相近的类别**：`S9.M2.1` — 区分点：少答 → 本叶；答错对象 → M2.1

# 环节 S9：终稿生成

把已有材料组织成最终答复与中间产物。含终稿生成轮、中间推理处理、display。失效多为编造、口径错、答非所问。

## 0. 判定骨架（按顺序问，命中即停）

1. **这一环该做的动作，一点都没做？** → `S9.M1.1` 整段无实质内容 / `S9.M1.2` 取回的数据没写进答案
2. **动作做了，但对象/指标/时段/范围不是用户要的？** → `S9.M2.1` 答错对象：把 A 当成 B / `S9.M2.2` 口径答偏：问这答那
3. **调用报错/超时/零行/空返回/被截断？** → `S9.M3.1` 图表引用解析失败
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S9.M4.1` 残缺材料当完整证据
5. **数据对，但换算/聚合/口径/比较错，或自相矛盾？** → `S9.M5.1` 旧数据当当前值 / `S9.M5.2` 同一答复内数值矛盾 / `S9.M5.3` 数值推算算错 / `S9.M5.4` 指标含义认错 / `S9.M5.5` 换算算错 / `S9.M5.6` 多标的汇总重复计数
6. **结论没证据，或与已有证据相反？** → `S9.M6.1` 编造不存在的对象 / `S9.M6.2` 违背已有证据 / `S9.M6.3` 证据不足仍下绝对结论 / `S9.M6.4` 凭空补出数值 / `S9.M6.5` 引用来源错挂 / `S9.M6.6` 取数失败被说成业务结论 / `S9.M6.7` 多源冲突未核验
7. **形式与完整性不达标（缺项/格式/语言/答非所问）？** → `S9.M7.1` 正文泄漏内部标记 / `S9.M7.2` 图没渲染只留占位 / `S9.M7.3` 答复不可读 / `S9.M7.4` 漏交付要求内容

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S9.M1.1` 整段无实质内容  ·  47 条 / 46 会话

- **定义**：对可回答的请求直接拒答、只给泛化免责声明，或整段未回应，用户拿不到任何实质内容。
- **可观测信号**：回答仅免责声明/复述问题，无任何结论
- **纳入**：含“无法提供/不构成投资建议”式空转、只复述问题。
- **排除**：已取回材料但没写进答案 → S9.M1.2。
- **最相近的类别**：`S9.M1.2` — 区分点：没内容 → 本叶；有材料没用 → M1.2
- **标签**：缺失 ｜ **组件**：中间推理处理、终稿生成轮
- **正例**：seq=9175「终稿误读上下文并以澄清反问代替回答」；seq=634「终稿只输出推理脚手架且答案区块为空」
- **反例（属 `S9.M1.2`，不属本叶）**：seq=1406「可用涨幅数据被低报并遗漏」

### `S9.M1.2` 取回的数据没写进答案  ·  121 条 / 115 会话

- **定义**：链路已取回可用数据，终稿却沉默跳过、换源或把问题抛回用户，材料未参与结论。
- **可观测信号**：上下文有工具结果，答案未引用、换源或抛回用户
- **纳入**：含弃用已取回的筛选结果、明明有数据仍说“未获取”。
- **排除**：否认或反转在手数据 → S9.M6.2。
- **最相近的类别**：`S9.M6.2` — 区分点：沉默跳过 → 本叶；否认/反转 → M6.2
- **标签**：缺失 ｜ **组件**：中间推理处理、终稿生成轮
- **正例**：seq=1406「可用涨幅数据被低报并遗漏」；seq=5871「弃用已取回的筛选结果并误判能力」
- **反例（属 `S9.M6.2`，不属本叶）**：seq=9490「来源结论被反转/选择性引用」

### `S9.M2.1` 答错对象：把 A 当成 B  ·  74 条 / 64 会话

- **定义**：终稿讨论的标的、公司身份或代码与用户所指不一致（同名混淆、把 A 写成 B、把指数写成个股）。
- **可观测信号**：答案讨论的标的/公司/代码≠用户所指
- **纳入**：含回答对象集合偏离用户指代的公司组。
- **排除**：口径/维度偏离 → S9.M2.2。
- **最相近的类别**：`S9.M2.2` — 区分点：对象错 → 本叶；对象对口径错 → M2.2
- **标签**：实体 ｜ **组件**：中间推理处理、终稿生成轮
- **正例**：seq=174「证券代码与公司张冠李戴」；seq=3110「结果表公司身份张冠李戴」
- **反例（属 `S9.M2.2`，不属本叶）**：seq=5「答复时段与用户提问不一致（日间→晚间）」

### `S9.M2.2` 口径答偏：问这答那  ·  81 条 / 68 会话

- **定义**：标的正确但回答的指标、时段、场景或人群口径不是用户问的那个（问日间答晚间、问季度答年度、问 A 股答美股）。
- **可观测信号**：指标/时段/场景与提问不符（问日间答晚间）
- **纳入**：含把用户限定条件改写后作答。
- **排除**：实体层面就错 → S9.M2.1。
- **最相近的类别**：`S9.M2.1` — 区分点：口径错 → 本叶；对象错 → M2.1
- **标签**：口径 ｜ **组件**：中间推理处理、终稿生成轮
- **正例**：seq=5「答复时段与用户提问不一致（日间→晚间）」；seq=976「终稿混入上一轮诉求并把回答推回用户征询」
- **反例（属 `S9.M2.1`，不属本叶）**：seq=174「证券代码与公司张冠李戴」

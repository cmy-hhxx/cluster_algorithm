# 环节 S3：结构化取数

执行结构化取数与 SQL。含 finquery 取数服务。失效多为解析/执行报错、零行、字段丢失、口径错。

## 0. 判定骨架（按顺序问，命中即停）

1. **这一环该做的动作，一点都没做？** → `S3.M1.1` 假装取数：返回常量占位
2. **动作做了，但对象/指标/时段/范围不是用户要的？** → `S3.M2.1` SQL 标的映射错 / `S3.M2.2` 不是取数问题也硬跑 SQL / `S3.M2.3` 复杂问题压成单指标榜单 / `S3.M2.4` 指标被近似字段顶替 / `S3.M2.5` 取数时点解析错 / `S3.M2.6` 执行时丢了规划条件 / `S3.M2.7` SQL 过滤失效返回全市场 / `S3.M2.8` 取数市场域解析错
3. **调用报错/超时/零行/空返回/被截断？** → `S3.M3.1` SQL 解析阶段报错 / `S3.M3.2` SQL 执行报错 / `S3.M3.3` SQL 条件写死必零行 / `S3.M3.4` SQL 零行仍报成功 / `S3.M3.6` SQL 字段不被支持 / `S3.M3.7` SQL 空结果当成功 / `S3.M3.8` SQL 输出被截断
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S3.M4.1` SQL 字段被静默丢弃 / `S3.M4.2` SQL 只回标识列 / `S3.M4.3` 要区间只回一个点 / `S3.M4.4` SQL 行数失控 / `S3.M4.5` SQL 缺交易日列 / `S3.M4.6` SQL 缺值用占位顶替 / `S3.M4.7` SQL 返回过期快照
5. **数据对，但换算/聚合/口径/比较错，或自相矛盾？** → `S3.M5.1` SQL 财报期间口径错 / `S3.M5.2` 单位量纲混用 / `S3.M5.3` SQL 聚合窗口算错 / `S3.M5.4` SQL 标签数值错位
6. **结论没证据，或与已有证据相反？** → `S3.M6.1` SQL 固定结论

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S3.M1.1` 假装取数：返回常量占位

- **定义**：取数服务把非数据请求（元指令、非投顾问题）翻译成不访问库表的常量 SELECT 或拒识语句，返回一行占位文本并标成功，最小取数动作未发生。
- **可观测信号**：SQL 无 FROM 业务表 / 返回常量文本；status ok 且 row_count=1
- **纳入**：SQL 无 FROM 业务表、返回固定文本、row_count=1 但无业务字段。
- **排除**：真正执行失败 → S3.M3.1/S3.M3.2。
- **最相近的类别**：`S3.M3.1` — 区分点：返回占位文本 → 本叶；参数为空没跑 → M1.2
- **标签**：失败 ｜ **组件**：finquery

### `S3.M2.1` SQL 标的映射错

- **定义**：把请求中的标的（公司/代码/指数/ETF/币种/商品）链接成另一只证券或另一市场品种，并以该标的的数据正常返回。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：返回标的≠请求标的，但查询语义本身正确
- **纳入**：返回数据的标的与用户所指不一致，但查询语义本身没问题。
- **排除**：后端把正确代码替换成别家（代码无误）→ S3.M4.6。
- **最相近的类别**：`S3.M4.6` — 区分点：请求侧映射错 → 本叶；后端把正确代码换掉 → M4.6
- **标签**：实体 ｜ **组件**：finquery

### `S3.M2.2` 不是取数问题也硬跑 SQL

- **定义**：输入根本不是取数请求（观点、计划、新闻事件、确认语、元指令、主观建议），服务不拒识不澄清，仍按金融表结构编 SQL 返回成批数据。
- **可观测信号**：输入是观点/元指令/确认语，仍返回成批数据行
- **纳入**：问题无数据诉求，却返回行情/财务表。
- **排除**：问题有数据诉求但被降维 → S3.M2.3。
- **最相近的类别**：`S3.M2.3` — 区分点：硬取数 → 本叶；降维成榜单 → M2.3
- **标签**：口径 ｜ **组件**：finquery

### `S3.M2.3` 复杂问题压成单指标榜单

- **定义**：把开放式、选股或归属类问题降维成单一指标的全市场排序、极值或计数，返回涨幅榜/宽表/计数，丢掉判断所需的多维指标。
- **可观测信号**：开放式问题返回单指标排序表/计数，多维指标丢失
- **纳入**：请求“哪些/为什么/是否值得”，返回一张单指标排序表。
- **排除**：请求本身就是单指标筛选 → 正常。
- **最相近的类别**：`S3.M2.4` — 区分点：降维成榜单 → 本叶；指标被换 → M2.4
- **标签**：口径 ｜ **组件**：finquery

### `S3.M2.4` 指标被近似字段顶替

- **定义**：请求指标在语义映射时被换成名称相近但口径不同的字段：52 周高低→日内高低、总收益→单日涨跌幅、RSV→RSI、代码 CCI→CCI 指标。
- **可观测信号**：返回列名近义不同义（RSV→RSI、总收益→单日涨跌）
- **纳入**：返回列名与请求指标名相近但定义不同，数值量级可辨。
- **排除**：字段根本没返回 → S3.M4.1。
- **最相近的类别**：`S3.M4.1` — 区分点：字段没返回 → M4.1；返回了别的字段 → 本叶
- **标签**：口径 ｜ **组件**：finquery

### `S3.M2.5` 取数时点解析错

- **定义**：日期、年份或相对时间被解析到错误时点（缺年份落到上一年、今天/次日混用）。
- **可观测信号**：SQL 的日期/表与用户说的时点/市场不符
- **纳入**：SQL 的日期/表选择与用户所说时点/市场不符。
- **排除**：时点对但取到过期数据 → S3.M4.7。
- **最相近的类别**：`S3.M2.8` — 区分点：取数时点解析错 → 本叶；取数市场域解析错 → S3.M2.8
- **标签**：时效,实体 ｜ **组件**：finquery

### `S3.M2.6` 执行时丢了规划条件

- **定义**：规划/语义 SQL 与真正下发的执行 SQL 在过滤值、筛选维度、排序或标的上不一致：主题词被替换、清单条件被丢弃、只剩单一价格条件。
- **可观测信号**：规划 SQL 与执行 SQL 的过滤/排序/标的不一致
- **纳入**：对比规划与执行两段 SQL 可见条件丢失或改写。
- **排除**：规划本身就错 → P 层。
- **最相近的类别**：`S3.M2.7` — 区分点：条件被改写但仍有过滤 → 本叶；过滤完全没生效 → M2.7
- **标签**：口径 ｜ **组件**：finquery

### `S3.M2.7` SQL 过滤失效返回全市场

- **定义**：过滤范围、主题词或板块映射与请求不符，返回全市场或错误板块的数据。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：返回全市场行、无有效 WHERE
- **纳入**：含“半导体”被映射成地区主题、缺标的过滤返回全市场无关行。
- **排除**：返回行数正常但内容不相关 → S3.M4.1。
- **最相近的类别**：`S3.M4.4` — 区分点：该过滤没过滤 → 本叶；行数失控但条件在 → M4.4
- **标签**：实体 ｜ **组件**：finquery

### `S3.M2.8` 取数市场域解析错

- **定义**：资产类别或市场域选错（加密送进美股表、A 股走港股表、商品当股票）。
- **可观测信号**：资产类别或市场域选错（加密送进美股表、A 股走港股表、商品当股票）。
- **纳入**：仅收 取数市场域解析错 这一类；具体现象见 definition。
- **排除**：若属于「取数时点解析错」→ S3.M2.5。
- **最相近的类别**：`S3.M2.5` — 区分点：取数市场域解析错 → 本叶；取数时点解析错 → S3.M2.5
- **标签**：时效,实体 ｜ **组件**：finquery

### `S3.M3.1` SQL 解析阶段报错

- **定义**：取数服务在问句解析/规范化环节直接失败，返回负 status_code（-3222/-3223/-3226/-3300/-3001 等）与“问句解析结果异常”，row_count/code_count 为 0。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：status_code -32xx/-3001；未生成有效 SQL；row_count=0
- **纳入**：finquery 侧解析阶段报错，未进入 SQL 执行。
- **排除**：SQL 已生成但执行报错 → S3.M3.2。
- **最相近的类别**：`S3.M3.2` — 区分点：失败在解析段 → 本叶；SQL 已生成、执行报错 → M3.2
- **标签**：失败 ｜ **组件**：finquery

### `S3.M3.2` SQL 执行报错

- **定义**：SQL 已生成但数据库执行失败：聚合列未进 GROUP BY、类型不兼容、未注册函数、表不存在、join 缺连接条件，返回 -2073/-2047/-2601 等。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：-20xx/-26xx；有 SQL 文本；GROUP BY/类型/表名错误
- **纳入**：错误码属执行段，或明确提示“SQL 取数异常”。
- **排除**：查询本身取不到数但不报错 → S3.M3.3。
- **最相近的类别**：`S3.M3.1` — 区分点：解析段就失败 → M3.1；执行段失败 → 本叶
- **标签**：失败 ｜ **组件**：finquery

### `S3.M3.3` SQL 条件写死必零行

- **定义**：SQL 谓词构造本身取不到数：等值比较代替区间、时间戳比日期字段、不存在的交易对/枚举、未来交易日、聚合等值过滤；执行必 0 行却以成功状态交付。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：谓词明显写错（等值代区间/未来交易日）；放宽也查不到
- **纳入**：条件明显写错（≠ 条件过严），放宽也取不到。
- **排除**：条件合理但确实无匹配 → S3.M3.4。
- **最相近的类别**：`S3.M3.4` — 区分点：条件本身错 → 本叶；条件合理但无匹配 → M3.4
- **标签**：失败 ｜ **组件**：finquery

### `S3.M3.4` SQL 零行仍报成功

- **定义**：查询语义与条件基本正确、执行成功但命中 0 行，服务以 status 0/ok 返回，不提示空结果、不放宽条件、不给替代口径。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：条件合理、row_count=0、status=0，无空结果提示
- **纳入**：条件无逻辑错误，只是市场/标的恰好无数据。
- **排除**：条件本身错 → S3.M3.3。
- **最相近的类别**：`S3.M3.3` — 区分点：条件错 → M3.3；只是没命中 → 本叶
- **标签**：缺失 ｜ **组件**：finquery

### `S3.M3.6` SQL 字段不被支持

- **定义**：调用被后端以参数不合法、字段不支持、请求格式错误为由拒绝，未产生任何数据。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：接口以"参数不合法/字段不支持/格式错误"拒绝
- **纳入**：含字段清单写法不被支持、参数类型不符。
- **排除**：参数为空导致根本没有发起取数，不属本叶。
- **最相近的类别**：`S3.M3.4` — 区分点：被上游拒绝 → 本叶；脚本自身报错 → M3.5
- **标签**：失败 ｜ **组件**：finquery

### `S3.M3.7` SQL 空结果当成功

- **定义**：执行返回空结果、错误体或异常文本，但工具层标记成功并继续下游。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：空输出/错误 JSON 被打上 success 继续下游
- **纳入**：含空输出、错误 JSON 当作正文、非零退出仍标 success。
- **排除**：返回部分数据但缺字段 → S3.M4.6。
- **最相近的类别**：`S3.M3.4` — 区分点：空结果被当成功 → 本叶；零行但状态正常 → M3.4
- **标签**：失败 ｜ **组件**：finquery

### `S3.M3.8` SQL 输出被截断

- **定义**：取数服务返回体被截断：结果行或字段在中途被裁掉（长度上限、预览、管道中断），请求的字段落在截断之外。
- **可观测信号**：输出末尾有省略标记；行数明显少于预期
- **纳入**：返回列/行数以省略号结尾，或明显少于预期且无错误码。
- **排除**：如果是字段根本没装配 → S3.M4.1。
- **最相近的类别**：`S3.M4.1` — 区分点：装配时丢字段 → M4.1；输出被截断 → 本叶
- **标签**：失败 ｜ **组件**：finquery

### `S3.M4.1` SQL 字段被静默丢弃

- **定义**：请求中的部分指标/字段在 SQL 生成或结果装配时被丢弃，返回 columns 与 datas 都没有该字段，status 仍 ok、row_count 正常。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：返回列少于请求列，status 仍 ok
- **纳入**：返回列少于请求列，且无报错。
- **排除**：字段被近似字段顶替 → S3.M2.4。
- **最相近的类别**：`S3.M4.2` — 区分点：少部分字段 → 本叶；只剩标识列 → M4.2
- **标签**：缺失 ｜ **组件**：finquery

### `S3.M4.2` SQL 只回标识列

- **定义**：返回 row_count≥1、status ok，但数据行只剩代码/名称等标识列，请求的数值指标整批为空或 null。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：有行，但请求的数值指标整批为空/null
- **纳入**：行存在、指标列全空。
- **排除**：整表无行 → S3.M3.4。
- **最相近的类别**：`S3.M4.1` — 区分点：缺几列 → M4.1；指标全空 → 本叶
- **标签**：缺失 ｜ **组件**：finquery

### `S3.M4.3` 要区间只回一个点

- **定义**：带日期区间、多期或多情景的请求只返回最新单时点/单报告期的一行一列，区间序列与多期分项缺失，且标记成功。
- **可观测信号**：请求 N 期/多情景，只返回最新 1 期
- **纳入**：请求 N 期，返回 1 期。
- **排除**：返回多期但期间口径错 → S3.M5.1。
- **最相近的类别**：`S3.M5.1` — 区分点：只是少给 → 本叶；给了但期间错 → M5.1
- **标签**：缺失 ｜ **组件**：finquery

### `S3.M4.4` SQL 行数失控

- **定义**：返回行数与请求对象数不符：未按股票聚合、TopN 前未去重、明细替代共识、聚合值被广播成多行，或命中面过大撞行数上限被截断。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：行数异常膨胀或恰好等于行数上限
- **纳入**：行数异常膨胀或恰好等于上限。
- **排除**：缺行（少返回标的）→ S3.M4.6。
- **最相近的类别**：`S3.M4.3` — 区分点：行太少 → M4.3；行太多/重复 → 本叶
- **标签**：多标的 ｜ **组件**：finquery

### `S3.M4.5` SQL 缺交易日列

- **定义**：返回数据的交易日/时点无法核对：缺 Trading Date 列、列标签日期与过滤日期不一致、latest 语义未生效而返回整段历史。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：缺 Trading Date 列；列标签日期≠过滤日期
- **纳入**：数据存在但无法判断 as-of 时点。
- **排除**：时点可核但数据过期 → S3.M4.7。
- **最相近的类别**：`S3.M4.7` — 区分点：无法判断时点 → 本叶；能判断但已过期 → M4.7
- **标签**：时效 ｜ **组件**：finquery

### `S3.M4.6` SQL 缺值用占位顶替

- **定义**：返回缺字段、缺行或缺标的时，用 0、N/A、None、常量或空串顶替，不报错不标注；含后端把请求标的替换为其他标的。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：缺失被 0/N/A/None/常量顶替；批量中个别标的整段消失
- **纳入**：数值看似正常但实为占位；批量查询中个别标的整段消失。
- **排除**：字段被顶替为近似指标 → S3.M2.4。
- **最相近的类别**：`S3.M2.4` — 区分点：占位顶替 → 本叶；被近似字段替换 → M2.4
- **标签**：缺失 ｜ **组件**：finquery

### `S3.M4.7` SQL 返回过期快照

- **定义**：返回历史缓存或过期快照，未按请求时点刷新，也未标注数据时间。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：返回历史缓存/前一日收盘当现价，未标数据时间
- **纳入**：价格/持仓与请求时点明显不符（如前一日收盘当现价）。
- **排除**：时点完全不可核 → S3.M4.5。
- **最相近的类别**：`S3.M4.5` — 区分点：时点错 → 本叶；时点不可核 → M4.5
- **标签**：时效 ｜ **组件**：finquery

### `S3.M5.1` SQL 财报期间口径错

- **定义**：返回的财务指标期间口径与请求不符：要 latest quarter 给 TTM、要 TTM 给单季或均值、要最新值给区间均值。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：TTM/单季/均值 标签与实际期间不符
- **纳入**：含季度自由现金流被标为 TTM。
- **排除**：期间对但单位错 → S3.M5.2。
- **最相近的类别**：`S3.M4.3` — 区分点：期间错 → 本叶；只回一个点 → M4.3
- **标签**：口径 ｜ **组件**：finquery

### `S3.M5.2` 单位量纲混用

- **定义**：同一指标在不同调用或同一行内单位与量纲不一致（小数 vs 百分数、复权前后量级差数十倍），未校验未标注。
- **可观测信号**：小数 vs 百分数、复权前后、股/手混用，量级差数十倍
- **纳入**：含成交量与市值量纲混用致倍数错误。
- **排除**：期间/窗口错 → S3.M5.1/S3.M5.3。
- **最相近的类别**：`S3.M5.4` — 区分点：换算错 → 本叶；标签与数值错位 → M5.4
- **标签**：单位 ｜ **组件**：finquery

### `S3.M5.3` SQL 聚合窗口算错

- **定义**：对已取到数据的聚合与排序算错：均值窗口含当日、同名指标窗口长度不一致、区间聚合值填充到逐日、排序方向与筛选语义相反。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：均值窗口含当日、窗口长度不一致、排序方向反
- **纳入**：含统计分桶与抽样口径不一致。
- **排除**：取数阶段就没取到正确序列 → S3.M4.3。
- **最相近的类别**：`S3.M5.4` — 区分点：算法错 → 本叶；标签对不上数值 → M5.4
- **标签**：口径 ｜ **组件**：finquery

### `S3.M5.4` SQL 标签数值错位

- **定义**：输出标签、标题、单位与实际数值窗口不匹配，或同一交付内两组数字互相矛盾（含硬编码常量与实算参数不符）。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：标签/单位/期间与数值窗口不匹配，或同一交付内自相矛盾
- **纳入**：含“季度”标签配年度数值、交割比例与成交量冲突。
- **排除**：纯计算错误且标签正确 → S3.M5.3。
- **最相近的类别**：`S3.M5.2` — 区分点：标签错位 → 本叶；单位换算错 → M5.2
- **标签**：口径 ｜ **组件**：finquery

### `S3.M6.1` SQL 固定结论

- **定义**：整段结论为固定文本/常量，未随本次数据变化，却以计算结果名义交付。（本叶仅收 finquery 取数服务 产生的缺陷）
- **可观测信号**：整段结论为固定文本，不随本次输入变化
- **纳入**：同一模板输出在不同输入下完全相同。
- **排除**：基于残缺数据外推 → A 层 M6。
- **最相近的类别**：`S3.M3.7` — 区分点：固定文案 → 本叶；空结果当成功 → M3.7
- **标签**：编造 ｜ **组件**：finquery

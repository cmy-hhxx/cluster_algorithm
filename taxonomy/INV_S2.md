# L1=S2 检索规划

把问题翻译成网页检索请求的阶段。含 planner-search、实体识别。失效多为检索词构造、时效锚点、歧义实体未消解。

## 0. 判定骨架（按顺序问，命中即停）

1. **这一环该做的动作，一点都没做？** → `S2.M1.1` 检索零查询 / `S2.M1.2` 追问未重新检索 / `S2.M1.3` 检索计划未执行
2. **动作做了，但对象/指标/时段/范围不是用户要的？** → `S2.M2.1` 检索词照抄原句 / `S2.M2.2` 检索标的认错 / `S2.M2.3` 检索词写入臆造实体 / `S2.M2.4` 检索时效锚点错 / `S2.M2.5` 检索目标维度取偏 / `S2.M2.6` 检索漏掉覆盖维度 / `S2.M2.7` 检索条件过窄 / `S2.M2.8` 检索词泛化重复 / `S2.M2.9` 检索意图判错
3. **调用报错/超时/零行/空返回/被截断？** → `S2.M3.1` 检索计划未产出
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S2.M4.1` 实体识别结果残缺
6. **结论没证据，或与已有证据相反？** → `S2.M6.1` 未检索即下结论

> 同一环节内，先定机制再定叶子。跨机制的兄弟不互斥，靠本节顺序裁决。

## 2. 判定卡（互斥用）

### `S2.M1.1` 检索零查询  ·  29 条 / 23 会话

- **定义**：面对需要数据支撑的请求，规划输出空数组或判定“无需检索”，本轮零查询下发，链路在规划处断流。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：计划输出为 [] / 空 search 项；本轮无工具调用
- **纳入**：输出为 [] / 空 search 项 / 明确判定无需外部材料；下游只能用旧上下文或通用知识作答。
- **排除**：计划里有查询但执行侧未派发 → P.M1.3；计划有查询但执行报错 → P.M3.1。
- **最近邻**：`S2.M1.3` — 区分点：出现查询项但没被执行 → M1.3；压根没有查询项 → 本叶
- **标签**：缺失 ｜ **组件**：planner-search
- **正例**：seq=11010「检索规划子模型越权输出答案代替执行计划」；seq=10882「把实质分析请求误判为无需检索的确认语，输出空检索计划」
- **反例（属 `S2.M1.3`，不属本叶）**：seq=6561「检索计划打包多条查询导致末尾查询未被执行」

### `S2.M1.2` 追问未重新检索  ·  15 条 / 15 会话

- **定义**：多轮追问或核对轮次中，最新请求已指向新的标的/价位，规划仍输出空计划，直接复用历史数字或截图信息。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：session_round>1；计划为空；答案沿用历史数字或截图
- **纳入**：session_round>1、追问语义明确要求新数据，但计划为空且回答沿用旧值。
- **排除**：首轮空计划 → P.M1.1；计划非空但查错对象 → P.M2.2。
- **最近邻**：`S2.M1.1` — 区分点：首轮空计划 → M1.1；追问轮仍空 → 本叶
- **标签**：时效,缺失 ｜ **组件**：planner-search
- **正例**：seq=7573「检索规划输出空计划」；seq=8403「检索规划输出空计划、未发起任何检索」
- **反例（属 `S2.M1.1`，不属本叶）**：seq=11010「检索规划子模型越权输出答案代替执行计划」

### `S2.M1.3` 检索计划未执行  ·  13 条 / 13 会话

- **定义**：计划内容本身正确，但条目数超出执行侧派发能力或多查询塞进单项，排在后面的查询从未被调用。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：计划文本含 N 条查询，执行记录 < N
- **纳入**：计划文本里有的查询，执行记录里找不到对应调用。
- **排除**：计划为空 → P.M1.1；派发后返回空 → P.M3.1。
- **最近邻**：`S2.M3.1` — 区分点：执行了但返回空 → M3.1；根本没执行 → 本叶
- **标签**：缺失 ｜ **组件**：planner-search
- **正例**：seq=6561「检索计划打包多条查询导致末尾查询未被执行」；seq=3335「检索计划把多条查询打包进单个 search 块，实际执行」
- **反例（属 `S2.M3.1`，不属本叶）**：seq=1949「planner-search 输出中途截断、未产出检索计划」

### `S2.M2.1` 检索词照抄原句  ·  10 条 / 10 会话

- **定义**：把用户整句问句、口语陈述、操作指令或裸实体名直接写成一条 finquery 查询项，既无标的标识也无指标与时间范围，取数侧只能按字面猜语义。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：查询 content 与用户问句高度重合，无标的/指标/时间要素
- **纳入**：查询 content 与用户原句高度重合、缺少字段/时间/标的要素；常伴随后续解析异常或全市场无过滤结果。
- **排除**：查询要素齐全但选错字段 → P.M2.5；查询可执行但返回不相关 → Q 层对应叶。
- **最近邻**：`S2.M2.5` — 区分点：有结构化要素但选错字段 → M2.5；整句原样透传 → 本叶
- **标签**：缺失 ｜ **组件**：planner-search
- **正例**：seq=6589「检索规划任务单一且查询未面向可获取操作步骤」；seq=12322「检索规划未解析歧义代码即直接拼查询」
- **反例（属 `S2.M2.5`，不属本叶）**：seq=1743「检索式把"高看涨目标价"改写为"波段交易"主题，丢失目标价约」

### `S2.M2.2` 检索标的认错  ·  108 条 / 100 会话

- **定义**：查询中的标的与用户所指不一致：裸代码缺交易所/市场限定、拼写错误、资产类别误判、同名或近义代码未归一化。（本叶仅收 planner-search 检索规划子模型、stock_ner_parse 实体识别 产生的缺陷）
- **可观测信号**：查询里的代码/名称与用户所指不一致；裸代码无交易所后缀
- **纳入**：含 NER 把交易所名当股票、把 GOLD 解析为 GLD、跨市场同名。
- **排除**：查询里出现用户没提过的实体（凭空写入）→ P.M2.3。
- **最近邻**：`S2.M2.3` — 区分点：实体来自输入但解析错 → 本叶；输入里没有的实体 → M2.3
- **标签**：实体 ｜ **组件**：planner-search、stock_ner_parse
- **正例**：seq=11653「裸代码被当作公司股票生成检索词」；seq=9189「检索查询未做股票代码消歧导致返回同名公司内容」
- **反例（属 `S2.M2.3`，不属本叶）**：seq=11750「检索规划把用户未提及的平台实体写入查询」

### `S2.M2.3` 检索词写入臆造实体  ·  86 条 / 81 会话

- **定义**：查询串出现输入不支持的平台、品牌、公司、画像或前提，或把用户给定约束改写得更强/更弱，检索围绕未证实对象展开。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：查询出现输入未提及的品牌/平台/前提，或约束被改写
- **纳入**：含把助手自述假设固化进查询、把“某概念”扩写成具体产品代次。
- **排除**：实体来自用户但被解析错 → P.M2.2。
- **最近邻**：`S2.M2.2` — 区分点：实体在输入里但解析错 → M2.2；凭空写入 → 本叶
- **标签**：实体 ｜ **组件**：planner-search
- **正例**：seq=11750「检索规划把用户未提及的平台实体写入查询」；seq=4335「检索查询中写入错误公司名（Comstock 与 CMCS」
- **反例（属 `S2.M2.2`，不属本叶）**：seq=11653「裸代码被当作公司股票生成检索词」

### `S2.M2.4` 检索时效锚点错  ·  86 条 / 78 会话

- **定义**：查询的日期/时段锚点与请求时点或用户窗口不一致：锚到非交易日、过期月份季度、未解析的相对时间，或把区间收窄/放宽。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：查询日期≠目标日期；锚到非交易日/过期月份
- **纳入**：含缺年份日期落到上一年、YTD 未覆盖年初、快照日选在未来。
- **排除**：锚点正确但返回旧页面 → S 层时效叶；期间口径算错 → M5。
- **最近邻**：`S2.M2.6` — 区分点：时间对但维度缺 → M2.6；时间整体错 → 本叶
- **标签**：时效 ｜ **组件**：planner-search
- **正例**：seq=9025「检索查询只用相对时间词，缺少日期锚定导致返回过期旧闻」；seq=2735「相对时间检索锚点错误（把“下一次会议”锚到已过去的月份）」
- **反例（属 `S2.M2.6`，不属本叶）**：seq=10496「检索规划丢失用户数值筛选条件（beta≥1）」

### `S2.M2.5` 检索目标维度取偏  ·  12 条 / 11 会话

- **定义**：标的正确，但请求的指标/字段与用户所需口径不符：近似指标顶替本体指标、缺支撑结论的必需字段、请求不存在的字段。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：查询字段与用户指标名近义不同义（52周高低→日内高低）
- **纳入**：含 52 周高低→日内高低、总收益→单日涨跌、RSV→RSI、上行空间→目标价变动率。
- **排除**：字段在 SQL 生成/返回时被丢弃 → Q.M4.1；整个维度未规划 → P.M2.6。
- **最近邻**：`S2.M2.1` — 区分点：整句透传 → M2.1；有字段但选错 → 本叶
- **标签**：口径 ｜ **组件**：planner-search
- **正例**：seq=1743「检索式把"高看涨目标价"改写为"波段交易"主题，丢失目标」；seq=360「检索规划价格口径未统一」
- **反例（属 `S2.M2.1`，不属本叶）**：seq=6589「检索规划任务单一且查询未面向可获取操作步骤」

### `S2.M2.6` 检索漏掉覆盖维度  ·  115 条 / 107 会话

- **定义**：查询集存在但未覆盖任务必需维度或对象：期权链/权利金、实时现价、技术指标与 N 日区间、多标的中的其余标的、并列分支、完整名单、用户给定地域/排除/价格约束。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：子问题数 > 查询数；整类数据源缺失（期权/现价/其余标的）
- **纳入**：查询条数与子问题数不匹配，明显漏掉一类数据源或一类对象。
- **排除**：完全没有查询 → P.M1.1；查询了但范围过宽 → P.M2.7。
- **最近邻**：`S2.M2.5` — 区分点：少一个字段 → M2.5；少一整类 → 本叶
- **标签**：缺失 ｜ **组件**：planner-search
- **正例**：seq=10496「检索规划丢失用户数值筛选条件（beta≥1）」；seq=445「检索规划遗漏目标指标与N日区间」
- **反例（属 `S2.M2.5`，不属本叶）**：seq=1743「检索式把"高看涨目标价"改写为"波段交易"主题，丢失目标价约」

### `S2.M2.7` 检索条件过窄  ·  29 条 / 24 会话

- **定义**：过滤条件、排序键与结果粒度偏离需求：多重硬阈值收窄到无交集、擅自附加约束、排序方向相反、缺规模流动性下限、明细未聚合未限量。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：WHERE 条件多于用户要求；ORDER BY 方向相反；阈值叠加到无交集
- **纳入**：查询带上了用户没提的 WHERE 条件，或该聚合时取了明细、该 TopN 时取了全市场。
- **排除**：没带任何过滤导致全市场返回 → Q.M2.7 / Q.M4.4。
- **最近邻**：`S2.M2.6` — 区分点：条件过严/加错 → 本叶；缺维度 → M2.6
- **标签**：口径 ｜ **组件**：planner-search
- **正例**：seq=6651「检索查询未一致保留硬性数值筛选阈值」；seq=2818「检索 query 遗漏/改写用户市值筛选条件，检索结果与」
- **反例（属 `S2.M2.6`，不属本叶）**：seq=10496「检索规划丢失用户数值筛选条件（beta≥1）」

### `S2.M2.8` 检索词泛化重复  ·  80 条 / 76 会话

- **定义**：查询颗粒度停留在主题/板块/榜单层面，或同一意图被改写成多条近义查询，角度未分化，预算重复消耗且召回同质。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：多条查询语义重合；只有主题词没有可执行限定
- **纳入**：同一轮内多条查询语义重合、或只有主题词没有可执行限定。
- **排除**：查询打偏到另一对象 → P.M2.2。
- **最近邻**：`S2.M2.1` — 区分点：单条整句透传 → M2.1；多条同质 → 本叶
- **标签**：缺失 ｜ **组件**：planner-search
- **正例**：seq=3922「检索查询同质化、缺少个股行情维度」；seq=5316「检索查询高度重叠、未分化出可支撑 early trend」
- **反例（属 `S2.M2.1`，不属本叶）**：seq=6589「检索规划任务单一且查询未面向可获取操作步骤」

### `S2.M2.9` 检索意图判错  ·  47 条 / 43 会话

- **定义**：把用户问题判成另一类任务或路由到不匹配的来源（咨询→客服工单、数量问题→选股、结构化筛选→网页检索），或改写时改变问题指向、丢失限定。（本叶仅收 planner-search 检索规划子模型 产生的缺陷）
- **可观测信号**：路由到不匹配的任务类型或数据源（咨询→选股、筛选→网页）
- **纳入**：含把开放式问题收窄为当日选股、把复核请求判为行情播报。
- **排除**：意图正确但对象错 → P.M2.2。
- **最近邻**：`S2.M2.6` — 区分点：类别对但漏维度 → M2.6；类别判错 → 本叶
- **标签**：口径 ｜ **组件**：planner-search
- **正例**：seq=9087「检索规划来源选择与问题不匹配，召回无关材料」；seq=7897「结构化枚举查询被误判为网页检索并收窄为“penny st」
- **反例（属 `S2.M2.6`，不属本叶）**：seq=10496「检索规划丢失用户数值筛选条件（beta≥1）」

### `S2.M3.1` 检索计划未产出  ·  11 条 / 11 会话

- **定义**：规划输出在完整查询前被 token 上限/推理循环截断，或规划产出的查询被调用后返回 null/零条/无 output。（本叶仅收 planner-search 检索规划子模型、stock_ner_parse 实体识别 产生的缺陷）
- **可观测信号**：计划 JSON 不完整/被截断；调用返回 null 或零条
- **纳入**：计划 JSON 不完整、被截断、或调用结果为空对象。
- **排除**：计划完整但未派发 → P.M1.3。

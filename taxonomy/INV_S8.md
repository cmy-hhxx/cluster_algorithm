# 环节 S8：能力装载

把外部能力装入上下文：技能文件加载、图像理解。含 view_skill/read_file、understand_image。失效多为加载失败、参数没带上、图像数值算错。

## 0. 判定骨架（按顺序问，命中即停）

1. **这一环该做的动作，一点都没做？** → `S8.M1.1` 技能参数没带上
3. **调用报错/超时/零行/空返回/被截断？** → `S8.M3.3` 技能加载失败
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S8.M4.1` 技能/文件正文被截断
5. **数据对，但换算/聚合/口径/比较错，或自相矛盾？** → `S8.M5.1` 图像数值合计算错 / `S8.M5.2` 图像识读结果错误

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S8.M1.1` 技能参数没带上

- **定义**：技能/工具调用参数拼接缺失、只执行首个对象，动作未落地却返回成功。（本叶仅收 view_skill/read_file 产生的缺陷）
- **可观测信号**：空参数拼接 / 只执行首个对象，动作未落地
- **纳入**：含 view_skill 空参数、多对象拼接只跑一个。
- **排除**：参数非空但被拒 → T.M3.3。
- **最相近的类别**：`S8.M3.3` — 区分点：没带上参数 → 本叶；加载失败 → M3.3
- **标签**：失败 ｜ **组件**：view_skill/read_file

### `S8.M3.3` 技能加载失败

- **定义**：技能文件路径解析失败、反序列化报错、前置校验不通过，能力未加载即中止。（本叶仅收 view_skill/read_file、stock-screener 产生的缺陷）
- **可观测信号**：技能文件路径不存在/反序列化报错，能力未加载
- **纳入**：含 skill 文件不存在、参数 JSON 解析失败。；含技能参考文件或安装目录缺失
- **排除**：参数缺失 → T.M1.1。
- **最相近的类别**：`S8.M1.1` — 区分点：加载失败 → 本叶；参数没带 → M1.1
- **标签**：失败 ｜ **组件**：view_skill/read_file、stock-screener

### `S8.M4.1` 技能/文件正文被截断

- **定义**：调用 view_skill/read_file 取回的技能文件或正文在句中断开、字段缺失、语义不完整，无法支撑答复。
- **可观测信号**：内容在句中断开、尾部丢失、字段缺失
- **纳入**：含被长度上限截断、尾部丢失、文件只读到前半段。
- **排除**：技能加载失败 → S8.M3.3；图像理解结果错误 → S8.M5.1。
- **最相近的类别**：`S8.M3.3` — 区分点：截断 → 本叶；重复/乱码 → M4.2
- **标签**：呈现 ｜ **组件**：view_skill/read_file

### `S8.M5.1` 图像数值合计算错

- **定义**：从图像读取的数值在合计或换算时算错，与图像中可见数据矛盾。
- **可观测信号**：合计≠分项和、换算与图像可见数据矛盾
- **纳入**：含截图持仓合计与分项不一致、数量级读错。
- **排除**：数值本身读错（OCR 失败）→ S8.M5.2；持仓接口鉴权失败 → S4.M3.9。
- **最相近的类别**：`S8.M4.1` — 区分点：算错 → 本叶；读不全 → M4.1
- **标签**：单位 ｜ **组件**：understand_image

### `S8.M5.2` 图像识读结果错误

- **定义**：从图像截图中读出的字段本身就是错的：读数与图中可见内容不符、误读为不可能值、漏读或读反关键字段、虚构图中不存在的行。
- **可观测信号**：图像回执里的数值/字段与图中可见内容不符（读数错、误读为 0、虚构行）
- **纳入**：含现价被读成 0.000000、涨跌幅方向读反、漏读关键字段、虚构表格行。
- **排除**：读数正确但合计或换算算错 → S8.M5.1；返回内容被截断 → S8.M4.1；技能加载失败 → S8.M3.3。
- **最相近的类别**：`S8.M5.1` — 区分点：读数本身错 → 本叶；读数对但合计/换算算错 → M5.1
- **标签**：缺失,编造 ｜ **组件**：understand_image

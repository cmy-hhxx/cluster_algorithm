# 环节 S6：客服知识库

客服/帮助中心知识库的检索与答复。含 customer_services。失效多为超时、正文损坏、答非所问、编造入口。

## 0. 判定骨架（按顺序问，命中即停）

3. **调用报错/超时/零行/空返回/被截断？** → `S6.M3.1` 客服接口超时无结果 / `S6.M3.2` 客服返回空不报错
4. **有返回，但内容撑不起任务（不相关/样板/过期/缺字段）？** → `S6.M4.1` 客服正文被截断 / `S6.M4.2` 正文损坏 / `S6.M4.3` 客服答的是另一个问题 / `S6.M4.4` 只有套话和免责声明
6. **结论没证据，或与已有证据相反？** → `S6.M6.1` 编出不存在的功能入口 / `S6.M6.2` 指引自相矛盾
7. **形式与完整性不达标（缺项/格式/语言/答非所问）？** → `S6.M7.1` 客服答复缺项 / `S6.M7.2` 答的语言不对

> 同一环节内，先定机制，再选类别。跨机制的类别不互斥，靠本节顺序裁决。

## 2. 类别判定卡（用来区分互斥）

### `S6.M3.1` 客服接口超时无结果

- **定义**：customer_services 调用超时、无返回或连接失败，未产出任何答复。
- **可观测信号**：调用超时/连接失败，无任何返回
- **纳入**：含请求超时、工具异常退出。
- **排除**：有返回但内容坏 → T.M4.x。
- **最相近的类别**：`S6.M3.2` — 区分点：超时无返回 → 本叶；空返回但标成功 → M3.2
- **标签**：失败 ｜ **组件**：customer_services

### `S6.M3.2` 客服返回空不报错

- **定义**：工具返回空结果/空对象，但状态标记成功，调用方无法区分“真的没有”与“调用失败”。（本叶仅收 customer_services 产生的缺陷）
- **可观测信号**：空 body/list 标记成功，无法区分"真没有"
- **纳入**：返回空 body、空 list、空 dict。
- **排除**：返回文本损坏 → T.M4.2。
- **最相近的类别**：`S6.M3.1` — 区分点：有状态无内容 → 本叶；调用就没成功 → M3.1
- **标签**：失败 ｜ **组件**：customer_services

### `S6.M4.1` 客服正文被截断

- **定义**：返回内容在句中断开、字段缺失、语义不完整，无法支撑答复。（本叶仅收 customer_services 产生的缺陷）
- **可观测信号**：内容在句中断开、尾部丢失、字段缺失
- **纳入**：含被长度上限截断、尾部丢失。
- **排除**：整段重复 → T.M4.2。
- **最相近的类别**：`S6.M4.2` — 区分点：截断 → 本叶；重复/乱码 → M4.2
- **标签**：呈现 ｜ **组件**：customer_services

### `S6.M4.2` 正文损坏

- **定义**：返回正文出现整段重复、编码错乱、乱码、语义破损，不可直接引用。
- **可观测信号**：整段重复、编码错乱、夹杂不可读字符
- **纳入**：含同一段文字重复多遍、夹杂不可读字符。
- **排除**：内容可读但跑题 → T.M4.3。
- **最相近的类别**：`S6.M4.1` — 区分点：重复乱码 → 本叶；截断 → M4.1
- **标签**：呈现 ｜ **组件**：customer_services

### `S6.M4.3` 客服答的是另一个问题

- **定义**：返回的是另一主题的答复（平台错误、产品线错误、问题错配），与查询意图不符。
- **可观测信号**：平台/产品线/问题类型错配，答的是另一件事
- **纳入**：含问 A 产品返回 B 产品、问操作返回营销文案。
- **排除**：内容相关但缺步骤 → T.M7.1。
- **最相近的类别**：`S6.M6.2` — 区分点：主题错配 → 本叶；内容自相矛盾 → M6.2
- **标签**：口径 ｜ **组件**：customer_services

### `S6.M4.4` 只有套话和免责声明

- **定义**：返回套话、免责声明、寒暄或模板占位，没有可执行信息。
- **可观测信号**：只有套话/免责声明/"请联系客服"
- **纳入**：含“请联系客服”“建议咨询专业人士”式答复。
- **排除**：有实质内容但缺项 → T.M7.1。
- **最相近的类别**：`S6.M7.1` — 区分点：没有实质内容 → 本叶；有内容但漏项 → M7.1
- **标签**：缺失 ｜ **组件**：customer_services

### `S6.M6.1` 编出不存在的功能入口

- **定义**：返回中编造不存在的产品名、页面、按钮路径或事实，且与真实界面/记录矛盾。
- **可观测信号**：产品名/页面/按钮路径在材料中不存在
- **纳入**：含编造菜单层级、编造活动规则。
- **排除**：内容正确但自相矛盾 → T.M6.2。
- **最相近的类别**：`S6.M4.3` — 区分点：编造入口 → 本叶；答错主题 → M4.3
- **标签**：编造 ｜ **组件**：customer_services

### `S6.M6.2` 指引自相矛盾

- **定义**：同一答复内前后步骤矛盾，或给出的规则/费率/时限与事实不符。
- **可观测信号**：同一答复内步骤互斥；费率/时限与事实不符
- **纳入**：含两处说法互斥、金额与规则不匹配。
- **排除**：编造实体 → T.M6.1。
- **最相近的类别**：`S6.M6.1` — 区分点：自相矛盾 → 本叶；编造实体 → M6.1
- **标签**：编造 ｜ **组件**：customer_services

### `S6.M7.1` 客服答复缺项

- **定义**：内容切题但漏掉用户要求的子项、只给概述没有步骤，或格式/结构与要求不符。
- **可观测信号**：少步骤/少字段/格式与要求不符，内容切题
- **纳入**：含未给操作路径、未列所需字段。
- **排除**：内容跑题 → T.M4.3。
- **最相近的类别**：`S6.M4.4` — 区分点：漏项 → 本叶；只有套话 → M4.4
- **标签**：缺失 ｜ **组件**：customer_services

### `S6.M7.2` 答的语言不对

- **定义**：答复语言与用户提问语种不一致，或混入未翻译片段。
- **可观测信号**：语种与提问不一致，或混入未翻译片段
- **纳入**：含中文问句返回英文、混入未翻译术语。
- **排除**：内容错误 → T.M6.x。
- **最相近的类别**：`S6.M7.1` — 区分点：语言错 → 本叶；结构漏项 → M7.1
- **标签**：语言 ｜ **组件**：customer_services

## 2. 路由原则

1. **按故障责任域路由**：
   - 取数规划子模型 → `S1`；检索规划/实体识别 → `S2`；
   - 结构化金融/业务数据取数工具与取数技能脚本 → `S3`；
   - 本地计算、沙箱脚本执行、持仓查询 → `S4`；
   - 外部网页搜索与抓取 → `S5`；
   - 客服/FAQ 知识库 → `S6`；
   - 用户画像与记忆读写 → `S7`；
   - 技能装载、文件读取、图像理解 → `S8`；
   - 最终答复合成与中间推理总结 → `S9`；
   - 工具调用参数/代码/请求构造（`role=request_generation`）→ `S10`；
   - 图表 spec 生成与可视化渲染 → `S11`；
   - 多步任务拆解与编排规划 → `S12`。
2. **禁止输出 `S0` 或“其他”**。`tool` 填规范化工具英文/中文短标识，`label` 填 ≤12 字中文人读名。

# 03 L4 子类归类

你的任务：把已归入父叶 `{{LEAF}}` 的 {{N}} 条归因条目，进一步分到下方已定义的 4 级子类（`{{LEAF}}.<N>`）。

## 1. 判定规则

1. **唯一来源**：只能从下方「本次子类清单」里选择 `{{LEAF}}.<N>`，禁止新造或简写 id。
2. **先纳入、后排除**：先按各子类的 `include` 正向匹配；若多个子类都可解释，按 `exclude` 逐条排除。
3. **动作优先**：继承父层原则，看 `definition` 与 `reason` 里的实际失效动作，不按 `label` 字面关键词分类。
4. **边界标记**：两个子类都能自圆其说时，选定义最贴近的一个并置 `"edge": true`；有把握置 `false`。

## 2. 输出契约

只输出与输入等量的 JSONL，每行一个对象：

```json
{"seq": 12, "path": "{{LEAF}}.2", "edge": false}
```

不要解释、不要代码块、不要多余字段，`seq` 必须与输入逐一对应。
